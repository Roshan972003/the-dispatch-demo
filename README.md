# The Dispatch: demo dashboard (read-only snapshot)

A **static, read-only copy** of the dashboard for [The Dispatch](https://github.com/Roshan972003/the-dispatch), a newsletter intelligence engine for the Indian startup ecosystem (MESA C4, Problem Statement 17).

- It reads a frozen snapshot (`state.json`, taken 16 Oct 2026). It has **no backend, no database and no keys**, so nothing here can change the real system.
- The subscriber list is **sample data** (a generated list of 2,200 addresses). In this demo the counts are shown as 2,200 active and 16 bounced, the list's original sample state, rather than the live count after a later test bounce.
- Buttons that would change things (run selection, re-send the draft, add subscribers) are switched off and say so.
- The real project: https://github.com/Roshan972003/the-dispatch
